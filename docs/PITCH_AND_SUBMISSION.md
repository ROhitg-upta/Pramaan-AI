## 4. Unstop Submission Copy-Paste Template

### Project Title
`Pramaan AI — Autonomous Code Forensics & Viva Defense Engine for Student Projects`

### Short Description / Tagline (100 Characters)
`Har Code Ka Pramaan. Autonomous code forensics and AI viva defense engine for real student builders.`

### The Problem
`College group projects and hackathons suffer from a massive free-rider problem: 1 student codes while others take credit, or teams copy-paste entire repositories using LLMs without comprehension. Evaluators have only 3 minutes per team and cannot inspect 200 commits or ask deep questions to everyone, leading to unfair grading and unverified talent.`

### The Solution
`Pramaan AI automates code forensics and viva examinations: 1) Mines git commit frequency, churn ratios, and atomic cadence to detect anomalous code dumps; 2) AST-weights code into boilerplate vs core algorithmic tiers; 3) Uses Gemini to generate line-grounded oral viva questions targeted to each student's exact commits; 4) Grades answers for tactical authenticity and generates a verifiable cryptographic Proof-of-Work Receipt.`

### Tech Stack Used
`FastAPI, Python 3.11, PyDriller, GitPython, Tree-sitter, Google Gemini 2.5 Flash, Next.js 14, TypeScript, Tailwind CSS, Framer Motion, Recharts, SQLite/SQLAlchemy.`

### Innovation & Uniqueness
`Unlike traditional plagiarism checkers (MOSS, Turnitin) that only compare static text similarity, Pramaan AI analyzes temporal git evolution, distinguishes boilerplate from core logic via AST, and dynamically interrogates contributors to verify genuine authorship.`

## 5. Anticipated Judge Q&A Defense

**Q1: "What if a student genuinely wrote all their code in an external IDE and committed it in one big commit at the end?"**  
*Answer:* *"That's why Pramaan AI combines forensics with the Autonomous Viva Defense. If a student wrote 4,000 lines offline, their commit cadence might flag an amber warning, but when they step into the Viva Hot Seat and ace the line-specific questions about their implementation trade-offs, their Pramaan Score balances out as a verified builder. Forensics flags anomalies; Viva verifies comprehension."*

**Q2: "What about developers who use AI coding assistants like GitHub Copilot or Cursor?"**  
*Answer:* *"Pramaan AI does NOT penalize AI usage—modern builders SHOULD use AI. Pramaan AI penalizes lack of understanding. If you used Copilot to write an authentication interceptor, you must still be able to defend how it handles expired tokens and edge cases during the viva."*

**Q3: "How does Pramaan AI handle large repositories quickly?"**  
*Answer:* *"Our ingestion pipeline applies depth limits, ignores vendor directories (`node_modules`, `dist`, lockfiles), and samples top Tier-3 commits based on AST complexity, allowing a complete forensic audit and viva generation in under 45 seconds."*
